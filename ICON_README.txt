ICON FILES NEEDED:

You need to add two Frenchie icon files:
1. icon-192.png (192x192 pixels)
2. icon-512.png (512x512 pixels)

These should be the same drooling Frenchie icon from the Android app!

For now, the app will work but won't show the icon when "Add to Home Screen" on iPhone.

To create these:
1. Export the Android app icon (ic_launcher.png)
2. Resize to 192x192 and 512x512
3. Save as icon-192.png and icon-512.png
4. Upload to your GitHub repo

The manifest.json already references these files!
